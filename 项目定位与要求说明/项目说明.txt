# 项目需求：虚拟手机桌面沉浸式AI聊天应用（完整版）
## 项目目标
开发仿手机桌面主页的沉浸式AI聊天应用，摒弃传统对话框首页。
产品形态：
1. 主载体：PWA（网页应用，浏览器打开、可添加到手机桌面）
2. 产出物：PWA网页 + 可打包Android APK，使用 Capacitor + GitHub Actions 自动打包
核心体验：打开就是虚拟手机系统桌面；AI交互通过弹窗、通知、可移动窗口、桌面小组件完成，不是传统聊天页面。

## 技术架构（严格遵守，不要擅自更换）
前端框架：Vue3 + Vite
样式：UnoCSS
状态管理：Pinia
路由：Vue Router
PWA：vite-plugin-pwa
图标：Iconify
拖拽核心依赖：@vueuse/core（useDraggable / useResizable）
AI通信层：统一 OpenAI 兼容协议封装，SSE 流式输出
APK打包：Capacitor
后端方案：初期纯前端，AI请求走配置里填写的接口地址，不自建后端服务。

## 【重点硬性要求1：AI接口兼容层】
接口模块必须做到：
- 遵循标准 OpenAI Chat Completions 格式，SSE stream 流式返回
- 兼容：OpenAI官方、DeepSeek官方、Gemini中转、各类第三方中转服务商
- 配置页可填写：BaseURL、API Key、Model Name、temperature、max_tokens
- 支持自定义请求头（适配很多中转站额外鉴权头）
- 错误统一捕获：401、404、限流、连接超时，给出可读提示
- 不要硬编码任何接口地址、密钥、模型名称，全部抽离到配置面板，本地持久化保存
- 切换中转站/官方站不需要改代码，只需要在软件内填参数
- 设置页内置【连通测试】按钮，发送简易请求校验配置是否正常

## 【重点硬性要求2：全桌面元素可移动】
桌面所有可交互元素支持拖拽，规则：
1. 桌面图标：长按拖拽、网格吸附、排序、长按弹出菜单（删除/改名）
2. 所有App应用窗口：可拖动标题栏移动、可缩放大小、最小化、关闭、置顶
3. 桌面小组件：自由拖拽摆放、可调整宽高、网格吸附
4. 拖拽边界：不能拖出虚拟桌面容器内部
5. 拖拽状态持久化：图标位置、窗口位置尺寸、小组件位置，全部存入localStorage，刷新页面自动还原布局
6. 动效：拖拽时轻微阴影提升、松手吸附动画，仿原生手机顺滑手感
7. 区分交互：拖动窗口内容区域不触发移动，只有标题栏拖动窗口；图标长按才启动拖拽，单击是打开应用

## 【核心App功能清单（全部为桌面独立App，点击图标唤起独立可拖拽窗口）】
> 所有App共用底层AI接口配置，共用一套中转/官方接口能力；每个App拥有独立会话上下文、独立UI、独立逻辑。
1. **微信**
虚拟社交聊天窗口，支持多对话会话，AI模拟好友对话，支持消息气泡、时间戳、消息通知；支持发送文字，流式AI回复；可保存聊天记录。
2. **世界书**
角色世界观设定工具。支持新建、编辑多条世界书条目（关键词+内容），开启/关闭条目；对话时自动把命中关键词的世界书内容注入AI上下文，用于人设、背景、剧情设定。
3. **设置**
全局系统设置面板。包含：AI接口配置（baseUrl、apikey、模型、自定义请求头、连通测试）、桌面壁纸设置、网格布局参数、动画开关、震动反馈开关、清除本地缓存、导入/导出全部本地数据。
4. **记忆**
长期记忆管理App。查看、新增、编辑、删除AI记忆条目；支持标签分类；记忆内容会选择性注入AI上下文，实现长期人设记忆、用户偏好记忆；支持记忆开关。
5. **商城**
虚拟商城页面（纯前端展示），展示角色卡、皮肤、壁纸、额外模板资源；本地标记已拥有资源，暂不接入真实支付。
6. **书院**
文本阅读&小说创作。支持新建文稿、分段写作；可以让AI续写、改写、润色文本；支持保存多篇文稿，支持导出文本。
7. **论坛**
虚拟论坛板块，支持发帖、楼层回复；AI可以扮演不同用户进行回帖互动；帖子本地保存，支持新建板块。
8. **文游**
文字冒险游戏模块。支持加载文游剧本，分支选择、剧情推进；AI驱动剧情生成，记录当前剧情存档，多存档保存。
9. **穿越局**
跨世界角色扮演交互，多世界观快速切换；可以绑定不同世界书组合，一键切换角色背景，独立剧情存档。
10. **抖音**
短文本信息流，上下滑动切换卡片；AI生成短文案、小故事、段子；卡片支持点赞标记，信息流本地缓存。
11. **游戏**
内置轻量化文字小游戏合集：猜词、海龟汤、情景小游戏，AI作为裁判/对手。
12. **信息**
短信式对话界面，简洁气泡消息，偏向简短日常消息、通知交互。
13. **塔罗**
塔罗占卜功能，选择牌阵、抽牌；AI结合牌面解读，生成解读文案；保存占卜记录。
14. **推特**
类似推特短动态界面，发简短动态，AI生成回复动态，时间线流式展示。
15. **情侣空间**
双人陪伴对话空间，专属会话上下文，情侣向人设对话、日记、共同记事。
16. **备忘录**
简易笔记工具，新建多条备忘录，纯文本记录，AI辅助总结、扩写笔记；自动保存。

## 分阶段开发计划
### 阶段1（优先）
1. 基础脚手架 + 目录搭建
2. 虚拟桌面容器、状态栏、壁纸切换、Dock栏
3. 图标拖拽、网格吸附、位置持久化
4. 统一 OpenAI 兼容 SSE 请求模块，Settings设置页，连通测试功能
5. 基础窗口外壳组件：可拖动、缩放、最小化、关闭、置顶
6. 优先开发核心App：设置、备忘录、微信、世界书、记忆，保证上下文注入逻辑正常

### 阶段2
1. 完善剩余App页面：书院、文游、穿越局、信息、塔罗、情侣空间、游戏
2. 桌面小组件，支持拖拽+调整大小，布局持久化
3. 世界书、记忆的上下文注入封装，每个App会话独立隔离
4. PWA完整能力：离线缓存、添加到主屏幕

### 阶段3
1. 剩余App：论坛、商城、抖音、推特，完成UI与基础交互
2. 系统通知模块，AI本地模拟主动推送通知弹窗
3. 移动端触感优化：点击震动、动画调校
4. 所有App本地数据持久化、导入导出功能

### 阶段4
1. Capacitor本地调试
2. GitHub Actions CI脚本，自动构建PWA并打包签名APK
3. 全量功能回归测试：切换多个中转站、切换模型、拖拽布局保存还原、各个App会话隔离测试

## 交互规则重申
✅ 首页永远是桌面，默认不打开聊天框
✅ 入口：图标点击打开对应App窗口 / 通知弹窗 / 桌面小组件
✅ AI支持本地模拟主动发消息通知
✅ 每个App窗口互相独立，上下文隔离，互不干扰
✅ 无强制回复压力，可以忽略消息、最小化窗口

## 硬性约束
1. 移动端优先，页面是竖屏虚拟手机容器
2. UI风格：磨砂玻璃、低饱和干净高级质感，拒绝花哨卡通
3. 禁止引入重型UI库（Element Plus / Ant Design Vue），组件自行封装
4. 所有拖拽逻辑基于 @vueuse/core，不要手写原生拖拽
5. 代码注释清晰，便于后续迭代
6. APK打包仅使用Capacitor，不用Cordova
7. 接口层不绑定任何一家服务商，保证切换中转零代码修改
8. 世界书、记忆注入逻辑解耦，可以灵活开启关闭，支持不同App单独控制是否读取记忆/世界书

## 你的工作方式
1. 先搭脚手架、目录，确认架构无误再开发
2. 严格按阶段顺序，完成一个阶段给我确认预览，再继续下一阶段
3. 遇到不确定的选型先提问，不要私自改动架构和接口规范
4. 所有位置、布局、App业务数据全部本地持久化
